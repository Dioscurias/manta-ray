# Manta visible brand rename

Rename the public-facing brand from “Manta Ray” to “Manta” everywhere visitors, assistive technology, search engines, and social previews encounter it. Preserve the manta artwork and the existing domain, routes, repository name, asset paths, storage keys, and internal CSS or JavaScript identifiers so the change cannot disrupt navigation, intro playback, or deployment.

The shared brand renderer remains the source for the header and footer. Page copy, intro copy, site configuration, SEO titles and descriptions, Organization JSON-LD, Open Graph labels, and accessibility labels use “Manta.” Tests assert the old public name is absent from rendered pages and metadata.
